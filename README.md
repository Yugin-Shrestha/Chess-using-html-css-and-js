# Chess By Yugin ♟️

Chess By Yugin is a local multiplayer chess game built using HTML, CSS, and JavaScript. It allows two players to play chess on the same device, with features such as legal moves, check, checkmate, castling, pawn promotion, move history, and more.

This project is part of my journey to learn and improve my web development skills.

✨ Features

♟️ Local Multiplayer — Two players can play on the same device.

♟️ Legal Moves — Prevents illegal chess moves.

👑 Check and Checkmate Detection — Detects check, checkmate, and stalemate.

♜ Castling — Supports kingside and queenside castling.

♟️ En Passant — Supports the special pawn-capturing move.

👑 Pawn Promotion — Promote a pawn to a queen, rook, bishop, or knight.

🔄 New Game — Restart the game at any time.

↩️ Undo Move — Take back the previous move.

🔃 Flip Board — Change the board's orientation.

⚔️ Captured Pieces — View pieces captured during the game.

📜 Move History — Keep track of moves played.

🎨 Responsive Design — Play on desktop and mobile screens.

🌐 No Chess Library — Chess rules and game logic are implemented using JavaScript.
